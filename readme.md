## Blandade kartor av Klas Karlsson.

### Eksjö Discgolf Park
Här finns utkast och kartor under framtagande. De är baserade på egeninhämtade data samt Lantmäteriets laserskannade öppna data. Synpunkter och förslag kan lämnas som "Issues" här på sidan. För detta krävs ett GitHub konto.

#### Banguide
Detta är den primära kartprodukten som det arbetas med för närvarande. Banguiden består av en översikt, 18 hålkartor samt en produktbeskrivning. Banguiden laddas ner som "Cards.pdf" från sidan.

#### Översiktskarta

Översikten är ett pågående arbete för att ta fram en ny bankarta för träningsområdet.
